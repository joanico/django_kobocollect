# django_kobocollect

This project integrates Django with Kobo Toolbox and Enketo Express for survey data collection and management.

## Documentation

- **[ENKETO_AND_KOBO_GUIDE.md](ENKETO_AND_KOBO_GUIDE.md)** - Guide for setting up and using Enketo Express and Kobo Toolbox
- **[DJANGO_INTEGRATION_GUIDE.md](DJANGO_INTEGRATION_GUIDE.md)** - Guide for Django integration with Enketo and Kobo

## Quick Start

1. Set up environment variables (see `DJANGO_INTEGRATION_GUIDE.md`)
2. Set up Enketo Express (see `ENKETO_AND_KOBO_GUIDE.md`)
3. Configure Kobo integration (see `ENKETO_AND_KOBO_GUIDE.md`)
4. Import forms and start collecting data

For detailed instructions, please refer to the documentation files above.
