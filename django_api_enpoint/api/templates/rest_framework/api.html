Welcome to the API documentation. Use the endpoints below to interact with the API.

Note: Click on any link below to view the data. The API uses Django REST Framework's browsable interface.

📋 Forms (Form Definitions)

Form definitions are the templates/structures of your forms (XForm XML).

  • View All Forms - List all form definitions (currently: 1 form)
  • View Form #1 - View details of form ID 1

To add a new form, use Django Admin or POST to /api/forms/

📝 Submissions (Form Data)

Submissions are the actual data entries submitted by users.

  • View All Submissions - List all form submissions (currently: 3 submissions)
  • View Submission #1 - View details of submission ID 1

To create a new submission, use Django Admin or POST to /api/submissions/submit/

📎 Media Files

Media files associated with forms.

  • View All Media - List all media files

API Endpoints (JSON)

  • GET /api/forms/1/ - Get form details (JSON)
  • GET /api/submissions/1/ - Get submission details (JSON)
